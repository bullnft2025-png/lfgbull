# Set 卡牌遊戲

一個基於經典 Set 卡牌遊戲的網頁版實現。

## 🎮 遊戲說明

Set 是一個考驗觀察力和邏輯思維的卡牌遊戲。玩家需要從桌面上的卡片中找出符合特定規則的三張卡片組合。

### 卡片屬性

每張卡片有四個屬性：
- **數量**：1、2 或 3 個符號
- **形狀**：菱形 (◆)、橢圓 (●) 或波浪 (~)
- **顏色**：紅色、綠色 或 紫色
- **填充**：實心、條紋 或 空心

### 如何組成 Set？

三張卡片組成一個有效的 Set 必須滿足：

**對於每個屬性，三張卡片的該屬性必須「全部相同」或「全部不同」。**

### 例子

✅ **有效的 Set**：
- 三張卡片都是紅色、都有 1 個符號、但形狀全不同、填充全不同
- 三張卡片的所有屬性都完全不同

❌ **無效的 Set**：
- 兩張紅色、一張綠色（顏色既不全同也不全異）
- 兩張有 1 個符號、一張有 2 個符號（數量既不全同也不全異）

## 🎯 遊戲功能

- **新遊戲**：開始一局新遊戲
- **提示**：系統會高亮顯示某個 Set 中的一張卡片（扣 5 分）
- **加三張卡片**：當找不到 Set 時，可以加入更多卡片
- **遊戲規則**：查看詳細的遊戲規則說明
- **計分系統**：
  - 找到一個 Set：+10 分
  - 選擇錯誤：-2 分
  - 使用提示：-5 分

## 🚀 如何開始

1. 直接在瀏覽器中打開 `index.html` 文件
2. 點擊三張卡片進行選擇
3. 如果三張卡片組成有效的 Set，會自動替換成新卡片
4. 如果無效，卡片會取消選取，你可以重新選擇

## 🎨 特色

- 精美的漸變色設計
- 流暢的動畫效果
- 響應式設計，支援手機和平板
- 完整的遊戲規則說明
- 遊戲結束統計

## 📱 響應式設計

遊戲支援各種螢幕尺寸，在桌面、平板和手機上都能流暢遊玩。

## 🛠️ 技術棧

- 純 HTML5
- CSS3（漸變、動畫、Flexbox、Grid）
- 原生 JavaScript（ES6+）

## 📝 遊戲玩法提示

1. 先觀察卡片的某一個屬性（如顏色），找出可能的組合
2. 確認其他三個屬性是否也滿足「全同或全異」的規則
3. 如果實在找不到，可以使用提示功能或加入更多卡片
4. 練習多了，你會越來越快找到 Set！
