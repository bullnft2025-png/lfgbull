Set 遊戲規則

什麼是 Set？

Set 是一個紙牌遊戲，目標是找出符合特定條件的三張卡片組合。

卡片屬性

每張卡片有四個屬性：

  • 數量：1、2 或 3 個符號
  • 形狀：菱形 (◆)、橢圓 (●) 或波浪 (~)
  • 顏色：紅色、綠色 或 紫色
  • 填充：實心、條紋 或 空心

如何組成 Set？

三張卡片組成一個 Set 必須滿足：

對於每個屬性，三張卡片的該屬性必須「全部相同」或「全部不同」。

例子

  • ✅ 有效的 Set：三張卡片都是紅色、都有 1 個符號、但形狀全不同、填充全不同
  • ✅ 有效的 Set：三張卡片的所有屬性都不相同
  • ❌ 無效的 Set：兩張紅色、一張綠色（顏色既不全同也不全異）

如何遊戲

  1. 點擊三張卡片選擇它們
  2. 如果組成有效的 Set，會自動從牌堆補充新卡片
  3. 如果無效，卡片會取消選取
  4. 找出所有可能的 Set 來獲得最高分！

🎉 遊戲結束！
